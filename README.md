## Обоснование сложности

### 160. Intersection of Two Linked Lists

**Подход — два указателя («перекрёстный забег»).**
Указатель `a` идёт по списку `A`, по достижении конца переходит на голову `B`;
указатель `b` идёт по списку `B`, затем переходит на голову `A`.

Если списки пересекаются и длина общей части равна `c`, то к моменту встречи
каждый указатель пройдёт одинаковое расстояние:

```
a + (b - c) = b + (a - c)
```

где `a`, `b` — длины списков до общей части. Если списки не пересекаются,
после одного перекрёстного прохода оба указателя одновременно станут `null`.

- **Время O(m + n)**: каждый указатель проходит максимум `m + n` узлов
  (свой список + чужой) до встречи или достижения `null`. Один цикл, без вложенности.
- **Память O(1)**: только две переменные-указателя. Альтернатива через хэш-таблицу
  посещённых узлов дала бы O(min(m, n)) памяти — хуже.

**Исключительные случаи**: пустые списки (`null`), отсутствие пересечения,
пересечение в первом узле, списки разной длины. Все покрываются общей логикой
без специальных веток (проверка на `null` в начале — только для обоих пустых списков).

### 166. Fraction to Recurring Decimal

**Подход — деление «в столбик» с картой остатков.**
Целая часть — `intdiv`. Дробная часть: на каждом шаге остаток умножается на 10,
очередная цифра — `intdiv(остаток * 10, знаменатель)`. Вычисления по модулю
остаются «чистыми»: каждый следующий остаток однозначно определяется предыдущим.
Как только остаток повторяется — найден период: цифры между первым и повторным
появлением остатка заключаются в скобки. Остаток стал `0` — дробь конечная.

- **Время O(d)**, где `d` — модуль знаменателя: различных ненулевых остатков
  при делении на `d` не более `d - 1`, значит цикл делает не более `d` итераций
  до повтора остатка или нуля. По условию задачи `|denominator| ≤ 2^31 − 1`,
  поэтому O(d) — effectively константа.
- **Память O(d)**: карта `остаток → позиция цифры` (не более `d` записей)
  плюс буфер цифр дробной части.

**Исключительные случаи**:
- `numerator == 0` → `"0"` без знака (не `"-0"`);
- знак результата через XOR знаков: минус только при разных знаках,
  `-2 / -1` даёт `"2"` без ведущего `+`;
- деление на ноль — `InvalidArgumentException` (на LeetCode гарантируется `denominator != 0`);
- переполнение `INT_MIN / -1`: в PHP `int` — 64-битный, `abs(PHP_INT_MIN)`
  помещается в `int`, поэтому нет переполнения, характерного для 32-битных языков
  (в C++/Java это отдельная ветка);
- целая часть без дробной (знаменатель делит числитель) → без точки;
- период из одной цифры (`1/3 → 0.(3)`) и длинный период (`1/7 → 0.(142857)`);
- непериодическая часть перед периодом (`1/6 → 0.1(6)`).
